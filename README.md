# Pac-Man Prototype in Unity (2D)

## Технології та Особливості Реалізації

* **Рушій:** Unity 2D / C#
* **Архітектура:** Використання патерну Singleton (`GameManager`) та архітектурного патерну обміну даними через `ScriptableObjects`.
* **Інтерфейс:** Сучасний текст на базі *TextMeshPro*, що включає динамічний HUD (очки, життя, прогрес пелетів), стартовий відлік (`3 -> 2 -> 1 -> GO!`) та екран результатів (Win / Game Over).

---

## Структура та Основні Скрипти

1. **`GameManager.cs`** — центральний «мозок» гри. Керує загальним станом рівня, підрахунком зібраних пелетів, умовами перемоги та поразки, а також перезавантаженням сцени.
2. **`GameConfig.cs`** (*ScriptableObject*) — виносить усі глобальні налаштування балансу (швидкість привида, кількість життів, ціль по пелетах, вартість балів) у окремі файли конфігурації.
3. **`PlayerMovement2D.cs`** — керує сітковим або плавним пересуванням Пакмана через колайдери та `Rigidbody2D`.
4. **`PlayerLife.cs`** — відповідає за систему життів Пакмана, фіксацію зіткнень з привидами (`Tag: Ghost`), анімацію миготіння при ударі та повернення на стартову позицію.
5. **`GhostPatrol.cs`** — забезпечує патрулювання привидів за заданим масивом точок (`Waypoints`) у коридорах лабіринту.
6. **`Pellet.cs`** — обробляє збір крапок гравцем, нараховує бали через `GameManager`, програє звуковий ефект збору (`AudioSource`) та знищує об'єкт.
7. **`GameUI.cs`** — відповідає за оновлення текстових полів HUD у реальному часі.
8. **`StartCountdown.cs`** — реалізує стартову затримку та відлік перед початком активного геймплею, тимчасово заморожуючи рух персонажів.

---

## 🚀 Як запустити гру

1. Відкрий проєкт у **Unity Hub** (рекомендована версія Unity 2D).
2. Перейди у папку `Assets/Scenes` і відкрий головну ігрову сцену.
3. Натисни кнопку **Play** у верхній панелі Unity.
4. **Керування:** Використовуй стрілочки або клавіші `W/A/S/D` для пересування Пакмана лабіринтом. Збирай пелети, уникай привидів та досягни цілі!
